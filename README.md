# Guessing Game

A simple console-based number guessing game built in Java. The program randomly
picks a number between 1 and 100, and the player has 7 attempts to guess it
correctly, with "too high" / "too low" hints after each guess.

## How to Run

```bash
javac GuessingGame.java
java GuessingGame
```
